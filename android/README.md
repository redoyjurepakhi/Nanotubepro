# Project: NanoTube
# Min SDK: 19 (Android 4.4 KitKat)
# Target SDK: 34
# Modern features: API Key rotation, Caching, Material Lite

This project is a lightweight YouTube client for older Android devices.
Built with Kotlin and Material Design components.

## Features
- Splash screen with fade animation
- YouTube Data API v3 integration with multi-key rotation
- RecyclerView for efficient memory usage
- Glide for robust image caching
- Android-YouTube-Player for lightweight, IFrame-based playback
- Search with suggestions
- Minimal settings for key management and themes
